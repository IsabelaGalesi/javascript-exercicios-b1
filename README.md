Exercícios de Revisão B1 - Desenvolvimento em JavaScript
Sobre o projeto

Projeto acadêmico desenvolvido para os exercícios de revisão da B1 da disciplina de Desenvolvimento em JavaScript, da Faculdade Anhanguera - Unidade Osasco.

O projeto apresenta um painel interativo com três funcionalidades desenvolvidas utilizando HTML, CSS e JavaScript.

Funcionalidades
1. Câmbio Comercial
Recebe um valor em reais (R$).
Converte o valor para dólares americanos (US 5,19).
Aplica uma taxa de serviço de 5% sobre o valor convertido.
Exibe o resultado final.


3. PDV - Aplicação de Descontos
Recebe o preço de um produto.
Permite selecionar um cupom de desconto.
Calcula o valor final do produto após a aplicação do desconto.

Cupons disponíveis:

CLIENTE_NOVO: 5% de desconto.
SOCIOTORCEDOR: 10% de desconto.
BLACKFRIDAY: 20% de desconto.
Sem cupom: nenhum desconto.


3. Simulador de Investimento
Recebe o capital inicial.
Permite informar a taxa de juros mensal.
Calcula o rendimento referente a um mês.
Exibe o resultado em reais (R$).

Como executar
Baixe ou clone o repositório.
Abra a pasta do projeto.
Abra o arquivo index.html no navegador.
Preencha os campos e clique nos botões para testar as funcionalidades.

Não é necessário instalar dependências para executar a versão atual.
